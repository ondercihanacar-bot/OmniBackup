# Auto-Git Push Rule for Antigravity

Whenever you complete a code modification, bug fix, feature addition, or task requested by the user in this repository:
1. Stage all relevant changed files: `git add .`
2. Commit with a meaningful, concise summary in Turkish: `git commit -m "..."`
3. Push changes directly to the remote repository: `git push origin main`
4. Confirm to the user that changes have been committed and pushed to GitHub.
